# 6. Presentation — 5%

## One-line pitch

> Eco-Alert AI เปลี่ยนหลักฐานสิ่งแวดล้อมจากประชาชนหลายรายการ ให้เป็นข้อมูลเหตุการณ์ที่พร้อมให้เจ้าหน้าที่ตรวจสอบและตัดสินใจ

## Problem

- รายงานประชาชนมาเป็นรายการแยกกัน
- ประชาชนไม่รู้หมวดหรือหน่วยงานปลายทาง
- เจ้าหน้าที่ต้องอ่านและเชื่อมข้อมูลจำนวนมากด้วยตนเอง
- เหตุที่ควรตรวจสอบก่อนอาจถูกมองเห็นช้า

## Solution

ประชาชนเพียงส่งสิ่งที่พบ จากนั้น AI Concierge:

1. เข้าใจหลักฐาน
2. เชื่อมรายงาน
3. ค้นบริบท
4. จัดกลุ่ม
5. จัดลำดับ
6. เตรียมข้อมูลให้เจ้าหน้าที่

เจ้าหน้าที่ยังเป็นผู้ตรวจสอบและตัดสินใจ

## ประโยคสำคัญ

- “เราไม่ได้ใช้ AI ตัดสินแทนเจ้าหน้าที่ แต่ใช้ AI ทำงานข้อมูลที่กินเวลา”
- “คะแนน 87 เป็นคะแนนจัดลำดับสำหรับ Prototype ไม่ใช่ค่าความรุนแรงทางวิทยาศาสตร์”
- “91% คือ confidence ของการจัดกลุ่ม ไม่ใช่ความมั่นใจว่ามีสารเคมี”
- “การส่งต่อใน Demo เป็น mock และเจ้าหน้าที่ต้องยืนยันทุกครั้ง”

## คำถามที่ควรเตรียมตอบ

### ทำไมต้องใช้ AI?

AI เหมาะกับการอ่านหลักฐานที่ไม่เป็นโครงสร้างและสรุปข้อมูลจำนวนมาก ส่วนคะแนนและ cluster ใช้ logic ที่ตรวจสอบได้

### ถ้า AI ผิดทำอย่างไร?

แสดง source, confidence และ reasoning; ไม่ทำ autonomous action; เจ้าหน้าที่ตรวจทุกขั้นสำคัญ

### ทำไมไม่ใช้ chatbot?

ปัญหาไม่ได้ต้องการการสนทนา แต่ต้องการ orchestration ระหว่าง evidence, data retrieval, clustering และ officer workflow

### เชื่อมระบบจริงหรือยัง?

Architecture และ adapters พร้อม แต่ data providers และ submission ปัจจุบันเป็น mock จนกว่าจะมี documented API และ authorization
